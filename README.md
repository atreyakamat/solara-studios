# Solara Studios

Static website for Solara Studios (website design and digital marketing in Goa), published at https://solara.atreyakamat.dev via Netlify.

- Plain HTML, CSS and a little JavaScript. There is no build step: Netlify publishes the repository root as-is.
- `hero.svg` is the cobalt engraved hero illustration. `og.png` is the 1200x630 social preview.
- The contact form uses Netlify Forms (`enquiry`). Add a notification email in Netlify under Forms.
- Preview locally: `npx serve .` or open `index.html` in a browser.
- The earlier React and Tailwind version of the site is kept on the `green-site` branch.
